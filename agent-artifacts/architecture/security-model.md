# Security boundaries
Public app visibility grants no access. Both apps enforce owner authentication on protected endpoints. Keep app cookies host-only, HttpOnly, Secure in production and SameSite=Lax. Secrets stay in encrypted server deployment configuration. Public registry fetches omit cookies; wildcard CORS applies only to public apps.json. App API CORS is not broadened. Linking uses a server action, authenticated session, password confirmation, random HttpOnly intent cookie and atomic consumption in the database. Google subject uniqueness prevents conflicting identities. Auth and account-link routes must bypass PWA runtime caches. Keep DB backups and rollback credentials until owner acceptance. No OAuth access or refresh tokens are stored by the launcher or included in the registry.
