# Google configuration
Verify or create the Google project aj-personal-platform after authorization; configure audience and test users as required. Create a separate Web OAuth client per app. Register its exact production origin and `<origin>/api/auth/callback/google`; localhost origins and callbacks must be registered separately for development. Do not assume the proposed health.ajoseph.dev is the current origin. Keep Health at its current origin during migration.

Health needs AUTH_OWNER_EMAIL matching the existing Health and Google email, AUTH_GOOGLE_ID and AUTH_GOOGLE_SECRET. Keep AUTH_SECRET and cookie identity unchanged. First set owner configuration and verify password access, then apply reviewed migration after backup, configure Google, log in with password and visit /account/google to link with password confirmation. Use a separate browser to test Google login before retirement. Journal keeps its existing configuration contract. See the Health migration runbook for detailed acceptance and rollback gates.
