# Integrate the menu
Install the vendored tarball as documented in the root README; include it in the app repository and lockfile. Add transpilePackages in Next config. Render `<AppLauncher currentApp="health" />` (or journal) in the app header. Default registry is https://apps.ajoseph.dev/apps.json. Override registryUrl only when intentionally targeting a test deployment. Permit the exact registry origin in connect-src. Do not add app cookies to requests, share app auth sessions or weaken API protection. Test the current-app label, unavailable registry, retry, empty list, Escape/focus and narrow viewport.
