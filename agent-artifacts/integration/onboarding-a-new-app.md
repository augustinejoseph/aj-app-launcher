# Onboarding an app
1. Write a spec using the template; create a separate repository and deployment.
2. Record real stack, data, auth and current origin in the inventory.
3. Configure app authorization and exact Google OAuth callbacks independently.
4. Provision only required DB/storage resources after authorization.
5. Add a validated registry entry; leave URL null and status unverified until tested.
6. Integrate a pinned launcher release and allow its public registry origin in CSP.
7. Test unauthorized API denial, owner login, responsive menu and keyboard behavior.
8. Verify HTTPS and deployment readiness, then mark the registry entry available.
